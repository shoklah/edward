# Kit pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One page, `/kits`, that shows for one kit at a time what its review found, what was acted on and what it cost, with the kit's facts on the run page, its warnings' family on Compliance and its checklist line on every finding.

**Architecture:** The import's schema reads `kits`, `kit_checks` and a finding's `label`, which stored runs already hold raw, so old runs fill in with no resync. A new pure view, `views/kits.ts`, sums over the period's stored runs behind `GET /api/kits`; the page is existing parts plus one small pair of columns. The run page's graph takes a box's kits and check chips from two new response fields.

**Tech Stack:** zod, Hono, Drizzle over SQLite, React, TanStack Query, Tailwind, Vitest, Storybook, Playwright. No dependency is added.

**Spec:** `docs/superpowers/specs/2026-11-24-kit-pages-design.md`; its captures are in `docs/design/2026-11-24-kit-pages/`.

**Kits:** `ui [react-tailwind-shadcn]` on tasks 2, 5 and 6.

## Global Constraints

- Every fact comes from the reporter; nothing is parsed here, and no fact is read out of a warning's text, a branch or a path. A missing fact is unknown (the dash), never zero.
- `kits[].files` holds absolute paths and is never read into the schema.
- Only Small and Full runs count. Figures of two kits are never added together, and no dispatch counts in two rows.
- Names, versions and checklist lines are text from units: `maskText` before summing. With a scope, sums count every project and only lists are filtered.
- Fixtures are invented text only. A hidden folder or branch name of a fixture is part of no response key and no other fixture text.
- `DESIGN.md` and the project's `CLAUDE.md` `## Code conventions` hold: one value per cell, zero muted, unknown a muted dash, numbers through the shared formatters, stories for every state, relative imports with their `.ts` extension.
- Copy is exactly as quoted in the tasks, the apostrophes and the `…` included.
- Each task's convention lines go under `## Code conventions` in the root `CLAUDE.md`, in the task's commit; in Wave A, they go in the report's `Conventions:` block instead.
- Run e2e on a free port: `E2E_PORT=<port> pnpm --filter @cwd/web exec playwright test --project=checks --project=checks-dark <files>`. Baselines: `pnpm test:screens --update-snapshots=changed` in Docker (start it if it isn't running), then look at every changed image before committing it.

## Review Focus

1. The chosen checklist line goes away under the reader (an import lands, showing mode starts): its findings close, and nothing names the line. (Task 5)
2. A run whose own cost is unknown: Share of run cost leaves it out, the dash when nothing is left, never `NaN`. (Task 3)
3. A kit named with a space, as showing mode's "another project": the Kit filter sends it and gets that kit back, and the select shows the pick while it loads. (Task 3, Task 5)
4. Showing mode hides every kit warning of the period: the list doesn't say there are none, and the hidden line counts them. (Task 5)

```ts
/** `GET /api/kits`'s query: the period's, plus `kit`, a kit's name as the response's `kits` lists it. */
export type KitsQuery = FindingsQuery & { kit?: string };
/** Findings, and those of them acted on (OUTCOME_GROUPS). */
export type Found = { found: number; actedOn: number };
/** A kind of review over runs: its steps, those whose counts are all zero, its findings by severity (the ruled one,
 * `unneeded` left out), those three severities' findings judged invalid, its re-checks, and its cost with theirs. */
export type ReviewSums = {
  ran: number;
  foundNothing: number;
  critical: Found;
  important: Found;
  minor: Found;
  invalid: number;
  rechecks: number;
  cost: number | null;
};
/** A checklist line's findings; null is the row of findings with no label. The five endings add up to `total`. */
export type KitLine = {
  label: string | null;
  critical: number;
  important: number;
  minor: number;
  total: number;
  actedOn: number;
  deferred: number;
  toOwner: number;
  open: number;
  noAction: number;
  invalid: number;
};
/** A project's runs of one path: `tasks` null when not known, `share` the kit's percent of the runs' cost. */
export type KitPath = ReviewSums & { path: 'full' | 'small'; runs: number; tasks: number | null; share: number | null };
/** A version's runs (null: not known), with the kit's last check results. */
export type KitVersion = ReviewSums & {
  version: string | null;
  runs: number;
  checks: { passed: number; failed: number; couldntRun: number };
};
```
